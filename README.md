# igy-preview

Staging space for Ingeniosity web work, published at https://preview.ingeniosity.co.uk (GitHub Pages, `main` branch, root).

- Managed by Claude (IGY Support Desk). Marc Blancher owns the repository.
- One folder per project and version: `/<project>/<slug>-v<N>/` (e.g. `/bimnc/logo-v1/`). Each preview is a full copy of the pages concerned, so the approved folder is exactly what gets deployed live (bim.nc → Lagoon FTP, by Marc).
- Every page carries `noindex`; `robots.txt` disallows crawling. No personal data, no secrets, nothing confidential is ever pushed here — the repository is public.
- Approval trail: the support ticket (`___WIP/IGY_Support_Desk/Register.md`) records which preview folder was approved and deployed.
